# Language Translator

This is a simple language translator project made using Python and Streamlit.

The project translates text from one language to another using Google Translator.

## Languages Supported

- English
- Hindi
- French
- German
- Spanish
- Japanese
- Marathi

## Modules Used

- streamlit
- deep-translator

## How to Run

First install the required modules:

```bash
pip install streamlit
pip install deep-translator
```

Then run the project using:

```bash
streamlit run app.py
```

## Project Files

```bash
app.py
README.md
```

## About Project

In this project user can:
- Enter text
- Select source language
- Select target language
- Translate the text

This project is useful for beginners who are learning Python and Streamlit.
